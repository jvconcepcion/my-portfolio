# 🌐 Web Portfolio – Jonathan V. Concepcion

## 🚀 About the Project
This is a **modern web portfolio** built using **Next.js** and **TypeScript**, designed to showcase my skills, projects, and experience in a sleek, interactive, and professional format. It includes a custom-built AI assistant named **Scaeva**, dynamic content loading from **Supabase**, encrypted credentials, and animations to enhance user experience.

## 🛠️ Tech Stack
- **Framework:** Next.js 16 (App Router, Turbopack, React 19, TypeScript 6)
- **AI Models:** OpenAI GPT (gpt-4o), OpenAI TTS (`tts-1`)
- **Security:** AES-256-CBC encryption, Base64 encoding
- **Styling:** Tailwind CSS v4, Framer Motion v12, Chakra UI
- **UI Components & Effects:**
  - `react-icons`, `react-icon-cloud`, `react-type-animation`, `swiper`, `react-countup`, `react-tagcloud`, `react-tsparticles`
- **Maps:** Leaflet, react-leaflet
- **Email:** Nodemailer
- **Database & Storage:** Supabase (PostgreSQL + Storage)
- **Package Manager:** pnpm
- **AI Assistant:** OpenAI GPT & TTS (with AES-256 encrypted API key)

---

## 🔐 Security
- OpenAI API key encrypted with AES-256-CBC and stored as an env var (`OPENAI_KEY_ENCRYPTED`)
- Decryption handled at runtime by `lib/decrypt.ts`
- Decryption password stored separately in `OPENAI_KEY_PASSWORD`
- All service credentials managed through environment variables — no hardcoded secrets

## 🟢 Supabase Integration
Supabase replaced Firebase/Firestore as the data and storage backend. It powers:

- **PostgreSQL tables:**
  - `content` — resume data, AI greetings, CV URL
  - `settings` — AI quota/status flag (`ai_status`)
  - `projects` — portfolio work items with `sort_order`
- **Storage bucket (`portfolio-assets`):**
  - `ui/` — background and decorative images
  - `avatar/` — AI assistant avatar
  - `audio/` — BGM tracks
  - `projects/` — project screenshot images
  - `documents/` — CV PDF

> All database reads/writes are in `lib/settings.ts`. Storage URLs are generated by `lib/storage.ts`.

## 🤖 Scaeva – AI Assistant

Scaeva is an AI-powered virtual assistant using OpenAI GPT. It responds to:

- General chat prompts
- Questions about me (CV-based context)
- Greetings and intros

**Features:**
- OpenAI GPT (gpt-4o) for completions, TTS (`tts-1`) for speech via `/api/chat/tts`
- Quota-exceeded detection with graceful UX — chat input disabled, Discord-style status dot turns red with "unavailable" label
- Status polling: `active` / `idle` / `offline` / `quota_exceeded`
- `localStorage` for message persistence
- Text-to-speech and clipboard support

## 🚀 Getting Started
### 1. Clone the Repository
\`\`\`bash
git clone https://github.com/jvconcepcion/my-portfolio.git
cd my-portfolio
\`\`\`

### 2. Install Dependencies
\`\`\`bash
pnpm install
\`\`\`

### 3. Setup Environment Variables
Create a \`.env.local\` file:
\`\`\`
OPENAI_KEY_PASSWORD=your_decryption_password
OPENAI_KEY_ENCRYPTED=your_aes256_encrypted_openai_key
NEXT_PUBLIC_USE_AI=true
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
\`\`\`

Preparation Steps:

- Encrypt your OpenAI API key using AES-256-CBC with a strong password
- Store the ciphertext as \`OPENAI_KEY_ENCRYPTED\` and the password as \`OPENAI_KEY_PASSWORD\`
- Create a Supabase project and provision the \`content\`, \`settings\`, and \`projects\` tables
- Upload assets to the \`portfolio-assets\` Storage bucket

### 4. Run the Development Server
\`\`\`bash
pnpm dev
\`\`\`
The portfolio will be available at [http://localhost:3000](http://localhost:3000).
